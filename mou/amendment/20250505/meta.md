# 規則等名
駒場祭委員会、五月祭常任委員会及び東京大学教養学部オリエンテーション委員会の共同プログラム開発に関する協定の実施に伴う駒場祭委員会及び五月祭常任委員会による共同プログラム開発に関する覚書の一部を改正する覚書

# 成立
令和７年５月５日 合意

# 施行
第76期駒場祭委員会の発足の日 施行（附則の規定による）
駒場祭委員会規約の規定により、令和７年５月１３日に施行したものと認められる。

# 成立の根拠及び方法等
第75期駒場祭委員会及び第98期五月祭常任委員会において、それぞれの規約にいう委員会総会においてシステム局長として指名された者が、駒場祭委員会、五月祭常任委員会及び東京大学教養学部オリエンテーション委員会の共同プログラム開発に関する協定（以下単に「協定」という。）第２条第５号にいう開発責任者として認められるから、これらの者が協定第１４条及び駒場祭委員会、五月祭常任委員会及び東京大学教養学部オリエンテーション委員会の共同プログラム開発に関する協定の実施に伴う駒場祭委員会及び五月祭常任委員会による共同プログラム開発に関する覚書（改正前のもの）第７条の規定に基づき合意した。両者署名し、捺印は省略した。

# 背景
協定第１４条の規定に基づき、駒場祭委員会及び五月祭常任委員会の間の共同開発等の合意事項等に関する仔細について、実際の運用を進めるにあたって、現状に鑑み補足し又一部を改める必要性が増したから、協議の上合意した。
