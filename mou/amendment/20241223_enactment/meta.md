# 規則等名
駒場祭委員会、五月祭常任委員会及び東京大学教養学部オリエンテーション委員会の共同プログラム開発に関する協定の実施に伴う駒場祭委員会及び五月祭常任委員会による共同プログラム開発に関する覚書

# 成立
令和６年１２月２３日 合意

# 施行
令和６年１２月２３日 施行（附則の規定による）

# 成立の根拠及び方法等
第75期駒場祭委員会及び第98期五月祭常任委員会において、それぞれの規約にいう委員会総会においてシステム局長として指名された者が、駒場祭委員会、五月祭常任委員会及び東京大学教養学部オリエンテーション委員会の共同プログラム開発に関する協定（以下単に「協定」という。）第２条第５号にいう開発責任者として認められるから、これらの者が協定第１４条の規定に基づき合意した。各会において公示等の方法をとることをもって、署名捺印は省略した。

# 背景
協定第１４条の規定に基づき、駒場祭委員会及び五月祭常任委員会の間の共同開発等の合意事項等に関する仔細を定める必要があったため、協議の上合意した。
