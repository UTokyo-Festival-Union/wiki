# 駒場祭委員会、五月祭常任委員会及び東京大学教養学部オリエンテーション委員会の共同プログラム開発に関する協定の実施に伴う駒場祭委員会及び五月祭常任委員会による共同プログラム開発に関する覚書

　（目的）
第１条　本覚書は駒場祭委員会、五月祭常任委員会及び東京大学教養学部オリエンテーション委員会の共同プログラム開発に関する協定（以下単に「協定」という。）第１４条の規定による委任に基づき、駒場祭委員会（以下「甲」という。）及び五月祭常任委員会（以下「乙」という。）両団体による共同プログラム開発等に関して、必要な事項を定め、甲の開発責任者（以下「丙」という。）及び乙の開発責任者（以下「丁」という。）の間で合意するところのものである。   
２　本覚書は、甲及び乙のみによる共同作成に限って適用する。

　（定義）  
第２条　本覚書における用語の定義は、協定及び次条に掲げるサービスによる。

　（管理）  
第３条　甲及び乙で共同作成したプログラム等のうち、主要なものは協定第９条第２項に定める方法で管理する。ただし、管理に用いるサービス等の事項は、次の表に示す通りとする。
| サービスの種類 | サービスの名称 | サービスのウェブサイトのURL |
| ---- | ---- | ---- |
| バージョン管理システム | Git | https://git-scm.com/ |
| リポジトリ管理プラットフォーム | GitHub | https://github.com/ |

|     |
| ---- |
| 備考　共同して管理するオーガニゼーション（URL「[https://github.com/UTokyo-Festival-Union](https://github.com/UTokyo-Festival-Union)」のウェブサイトで閲覧できるもの。以下この条及び第５条において単に「オーガニゼーション」という。）がプログラム等を含むリポジトリのオーナーシップを持つように設定する。 | 

２　協定第１０条に定める公開は、プログラム等を含むリポジトリの可視性をパブリックに設定することによって行う。  
３　協定第１２条に定める移転は、プログラム等を含むリポジトリのオーナーシップをオーガニゼーションに移転し、またはオーガニゼーションがオーナーシップを持つリポジトリを作成することによって行う。

　（文章の提供）  
第４条　協定第８条に定める文書の提供は、原則として丙及び丁の間での提供による。

　（開発の約束等）  
第５条　甲及び乙による共同作成について、協定及びこの覚書に定めのない共同開発における約束その他必要な仔細の事項は、必要に応じてオーガニゼーションがオーナーシップを保有する wiki レポジトリの main ブランチにおいて最新の状態として管理される文書の電磁的記録（該当しない旨特筆のあるものを除く。第７条において「ドキュメント」という。）によって、丙丁双方の責任のもと定めたものを記載しておく。

　（公開）  
第６条　この覚書は、協定の目的を達成し、及びこの覚書の締結を証するために、甲乙双方の公示その他の適切な方法により公開しておく。

　（改廃）  
第７条　この覚書の改廃は丙丁双方の合意による。改廃は、ドキュメント又は甲若しくは乙の公示において掲示する方法その他の適切な方法によって公開する。

## 　　　附　則  
この覚書は合意の日から施行する。
