# 規則等名
駒場祭委員会、五月祭常任委員会及び東京大学教養学部オリエンテーション委員会の共同プログラム開発に関する協定の実施に伴う駒場祭委員会及び五月祭常任委員会による共同プログラム開発に関する覚書の一部を改正する覚書

# 成立
令和８年４月１１日 合意

# 施行
合意の日 施行（附則の規定による）

# 成立の根拠及び方法等
協定第１４条及び駒場祭委員会、五月祭常任委員会及び東京大学教養学部オリエンテーション委員会の共同プログラム開発に関する協定の実施に伴う駒場祭委員会及び五月祭常任委員会による共同プログラム開発に関する覚書（改正前のもの）第１０条の規定に基づき、当該覚書にいう開発責任者である丙及び丁が合意した。署名及び捺印は省略した。

# 背景
協定は相互の技術開発の発展を目的とするものであるが、開発中のプログラムに不可分な文書の提供は覚書上可能であった一方、共同開発を行わずにプログラムそのものを他方に提供する方法については、覚書上明文化されていなかった。他方で、甲及び乙の業務は類似する部分が多く、単独開発プログラムの提供は一方通行に終わらず、提供を受けた側における改善その他の成果が他方又は双方に還元され得ることから、協定の目的に反しないものである。これらを踏まえ、単独開発プログラムの提供及びその趣旨に関する事項を定める必要性が生じたため、協議の上合意した。なお、当該事項は協定第８条に基づく文書等の提供（第６条）の枠組みとは性質を異にするため、単独開発プログラムの提供を第７条として新たに加え、従来の第７条から第１０条を繰り下げて整理した。
