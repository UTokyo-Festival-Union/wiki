# 規則等名
駒場祭委員会、五月祭常任委員会及び東京大学教養学部オリエンテーション委員会の共同プログラム開発に関する協定の実施に伴う駒場祭委員会及び五月祭常任委員会による共同プログラム開発に関する覚書の一部を改正する覚書

# 成立
令和８年１０月２０日 合意

# 施行
令和８年１０月２０日 施行（附則の規定による）

# 成立の根拠及び方法等
協定第１４条及び駒場祭委員会、五月祭常任委員会及び東京大学教養学部オリエンテーション委員会の共同プログラム開発に関する協定の実施に伴う駒場祭委員会及び五月祭常任委員会による共同プログラム開発に関する覚書第１１条の規定に基づき、当該覚書にいう開発責任者である丙及び丁が合意した。両者署名及び捺印を行った。

# 背景
合意同日に締結した共同開発協定の改正に伴う修正及び軽微な表記の変更を行う必要があったため、協議の上合意した。
